# Material excluded from the public release

The original `全包(1).zip` remains unchanged. This public derivative excludes:

- `.venv`, Python caches, local `.git` metadata and editor/OS files;
- `db.sqlite3`, database backups and generated local runtime state;
- duplicate source trees and superseded evidence deliveries;
- identity sheets, organisation-identifying records and names in processed
  validation outputs;
- signed consent forms, consent supersessions and ethics/governance records;
- raw researcher return ZIPs, raw key workbooks and original human-study HTML;
- pilot packages and sealed validation archives that contain controlled data;
- original/unredacted screenshots when a redacted counterpart exists;
- an older Thesis Tables A–J workbook whose consultation count and identifiers
  did not match the final report;
- older consultation/requirement notes inside the technical archive that retain
  names or uncertain public-redistribution consent.

The following were deliberately retained because the final report relies on
them: the authoritative source tree and manifests, final test logs, Formal 32
indexes and raw technical archive, A/B and MP/UCR evidence, historical v9
failure evidence, redacted current screenshots, de-identified researcher-study
results, Gold v0.8.0, current technical tables and the final PDF report.

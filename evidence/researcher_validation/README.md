# Researcher-validation evidence (public derivative)

The formal study used three relevant practitioners, coded `P01`–`P03`, each of
whom completed one Manual and one Prototype review task. The public directory
retains the processed evidence needed to inspect the reported results while
excluding identity-bearing and potentially re-identifiable raw returns.

## Public files

- `Researcher_Validation_Summary_PUBLIC.xlsx`: participant-coded condition,
  scoring, timing, preference, open-text and deviation tables.
- `Researcher_Validation_Data_PUBLIC.json`: de-identified processed analysis
  dataset.
- `Gold_v0.8.0_PUBLIC.xlsx`: Gold review with the reviewer labelled
  `GoldReviewer01`.
- `Result_Summary.txt`: concise reported results and interpretation boundary.
- `reproducibility_controlled_data/`: scoring rules, analysis script, tests and
  de-identified output records. The script requires controlled raw inputs and is
  therefore not fully runnable from the public repository alone.
- `release_records/`: de-identified authority, deviation, exclusion and scoring
  records.

## Not public

Raw participant ZIPs, response/manual workbooks, original Evidence Record HTML,
signed consent, pilots and identity sheets remain in the controlled archive.
This is a privacy boundary, not an assertion that the public aggregate data are
independent raw evidence.

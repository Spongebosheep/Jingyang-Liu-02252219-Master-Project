# Public reproducibility note

This directory is a de-identified copy of the formal analysis logic and its
outputs. Names in code, paths and logs have been replaced with participant or
role codes.

The original script expected the controlled raw participant packages and signed
study archive. Those inputs are intentionally absent from this public release,
so a complete public rerun is not possible. The included logic, scoring rules,
tests, hashes and de-identified processed outputs provide method transparency;
the controlled archive remains the authority for a full audit.

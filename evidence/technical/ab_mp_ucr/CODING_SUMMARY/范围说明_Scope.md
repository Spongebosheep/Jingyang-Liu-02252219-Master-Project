# 编码范围 / Coding scope

- 旧分析：只评价 MVP S7/S8 的 final-reviewed evidence。结果为 MP 8/9、UCR 3/46，UCR Cohen's kappa=0.789。
- 新 Phase 1/2：主要用于补齐 Baseline MP/UCR 缺口，评价10个完成配对中的 pre-review drafts。Baseline MP=45/45；UCR=0/220。去重后为9/9和0/46。
- 新材料同时包含逐字相同的 MVP 对应 draft-source 组合，因此技术上映射为同样的45/45与0/220；这不是另一轮独立 MVP 评价。
- 两组分析的阶段和材料范围不同，不得相加、平均、覆盖或直接用于条件优越性推断。
- 新 MP/UCR 的原始一致率均为100%，但两位 coder 只使用一个类别，所以 kappa 不可估计，不是1。

Earlier analysis assessed only final-reviewed MVP S7/S8 evidence. The later Phase 1/2 work was conducted primarily to fill the Baseline MP/UCR gap and assessed pre-review drafts from the 10 completed pairs. Text-identical MVP counterparts were present and receive the same mapped labels, but this is not a separate independent MVP evaluation. Do not pool or directly compare the two stages.

# Evidence index

This directory contains public-safe evidence selected against the final report.
It is not a copy of the complete controlled evidence delivery.

- [`CLAIM_EVIDENCE_MAP.md`](CLAIM_EVIDENCE_MAP.md) maps report claims to paths.
- [`technical/`](technical/) contains source-linked technical evaluation,
  masked quality review and historical iteration evidence.
- [`researcher_validation/`](researcher_validation/) contains de-identified
  processed human-study evidence and controlled-data analysis logic.
- [`figures/`](figures/) contains the report's workflow/design figures.
- [`screenshots_redacted/`](screenshots_redacted/) contains the selected
  public-safe interface screenshots.
- [`thesis_tables/`](thesis_tables/) contains current technical result tables.

The final report remains the authority for interpretation and claim boundaries.
Where an evidence archive contains later supplementary diagnostics, those
diagnostics must not be pooled with or substituted for the report's frozen
results.
